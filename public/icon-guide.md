# Icon Generation Guide for APK

## Required Icons for Android APK:
- **icon-192.png** (192x192 pixels)
- **icon-512.png** (512x512 pixels)

## Quick Icon Generation Options:

### Option 1: Use Favicon Generator (Easiest)
1. Visit: https://realfavicongenerator.net/
2. Upload any image with TMT/construction theme
3. Download the package and extract icon-192.png and icon-512.png

### Option 2: Use Canva (Custom Design)
1. Go to canva.com
2. Create 512x512px design
3. Use navy blue (#1e3a8a) background
4. Add orange (#f97316) text/icon: "TMT" or construction icon
5. Export as PNG at 512x512 and 192x192

### Option 3: Simple Text Icon
1. Visit: https://favicon.io/favicon-generator/
2. Text: "TMT"
3. Background: #1e3a8a (navy blue)
4. Font color: #f97316 (orange)
5. Download and rename to icon-192.png and icon-512.png

## Branding Colors:
- Navy Blue: #1e3a8a
- Orange: #f97316
